Product

Transparent cluster networking plus the tools you reach for every day.

Core capabilities

T

Transparent TUN

Managed sing-box routes only discovered Pod and Service traffic.

D

Cluster DNS

Split DNS with search domains — mysql.default and *.svc.cluster.local both work.

H

Host Aliases

Per-context domain → IPv4 maps via local DNS while connected. Reconnect to apply; cleared on disconnect.

C

Cluster management

Add kubeconfig files, list Contexts, probe and switch.

Developer tools

⇄

Exchange

Replace a ClusterIP Service with a process on your machine.

⧉

Mirror

Keep cluster Pods as the primary path and tee a copy of TCP/UDP requests to a local process.

◉

Preview

Expose a local app as a temporary ClusterIP Service.

↦

Port Forward

Forward a local port to a Pod or Service.

Minimal Gateway

Unprivileged in-cluster Deployment reached only via API Server port-forward. Works with scoped RBAC and admin-preinstalled Gateways.
