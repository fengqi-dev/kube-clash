Get started

Connect your machine to a cluster in a few minutes.

Connect once

Install KubeLoop

Download a platform package from GitHub Releases (or build from source with Wails). macOS: open the DMG and drag KubeLoop.app into Applications (or extract the tar.gz); if Gatekeeper blocks it, right-click → Open, or run xattr -cr KubeLoop.app. Windows: run the NSIS installer, or extract the portable zip; if SmartScreen appears, choose More info → Run anyway. Linux: install the deb / rpm, or extract the tar.gz and run KubeLoop.

Confirm kubeconfig access

Make sure this machine can reach the cluster API with a normal kubeconfig.

Select a Context and Connect

Open the Clusters page, pick a Context, optionally probe the API, then connect.

Approve the helper once

On first use, approve the virtual network service. Later connects should not ask again.

After you are connected

Use Overview for traffic and status, Workload / Network for Port Forward, Exchange, Mirror, and Preview, and Host Aliases for custom domain → IP maps. Short names like mysql.default resolve via Kubernetes search domains.
